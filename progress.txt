## Tailwind v4 토큰 방식 (CSS-first, tailwind.config.js 없음)
- globals.css 최상단: `@import "tailwindcss";` + `@import "tw-animate-css";`
- `@custom-variant dark (&:is(.dark *));` 로 dark variant 정의.
- 색/반경 토큰은 :root 에 정의 → `@theme inline { --color-*: var(--*) }` 로 매핑해야
  Tailwind 유틸(bg-jp-bg, text-jp-fg, bg-primary ...)로 노출됨. @theme inline 안 거치면 유틸 생성 안 됨.
- JobPilot 팔레트 + shadcn semantic(--background/--primary/--border/--ring 등) 둘 다 매핑.
  radius 14px = --radius: 0.875rem.
- 다크가 기본: html className="dark" + body bg-jp-bg. .dark 블록도 동일 토큰으로 채워 shadcn 패리티.

## MCP 응답 포맷 (핵심)
- MCP 서버 POST /mcp 호출 시 응답은 SSE 포맷: `event: message\ndata: {...}\n\n`
- data: 내 JSON 구조: `{ result: { content: [{type:'text', text: JSON문자열}], structuredContent: {...} }, jsonrpc:'2.0', id:1 }`
- **structuredContent 우선** 파싱 → 없으면 content[0].text JSON.parse.
- source 필드: structuredContent 내 `source: 'live'|'mock'|'cache'` 등 보존 필요.

## SSE 파싱 로직
- `res.text()` 전체 읽기 → `data: ` 프리픽스 줄 찾아 JSON.parse.
- plain JSON 폴백(헤더 Accept에 application/json, text/event-stream 둘 다 포함).
- AbortController로 8초 타임아웃. fetch 실패·타임아웃 시 `{error, source:'error'}` 반환(throw 안 함).
