## shadcn 셋업 — 함정과 해법 (중요)
- `pnpm dlx shadcn@latest init` 의 `--base-color` 플래그는 4.8.3 에서 제거됨 → "unknown option" 에러.
- 비대화형(non-TTY)에서 `init --help`/`init -d` 가 "Usage:" 만 무한 반복 출력하며 정상동작 안 함(터미널 없어서 prompt 루프).
- 결론: **shadcn init 자동화 대신 수동 셋업이 가장 안정적**. 다음처럼 했음:
  1. 런타임 deps 직접 설치:
     pnpm add class-variance-authority clsx tailwind-merge lucide-react \
       tw-animate-css next-themes sonner @radix-ui/react-slot @radix-ui/react-dialog
  2. components.json 직접 작성 (style: new-york, rsc: true, baseColor neutral,
     css: app/globals.css, aliases ui=@/components/ui, utils=@/lib/utils ...).
  3. lib/utils.ts 에 cn() (clsx + tailwind-merge).
  4. components/ui/*.tsx 직접 작성: button, card, badge, input, skeleton, dialog, sonner.
     (이후 컴포넌트 추가는 `pnpm dlx shadcn@latest add <name>` 시도하되, 막히면 수동 복붙.)
- lucide-react 는 1.17.0 설치됨(아이콘 import 정상).

## Tailwind v4 토큰 방식 (CSS-first, tailwind.config.js 없음)
- globals.css 최상단: `@import "tailwindcss";` + `@import "tw-animate-css";`
- `@custom-variant dark (&:is(.dark *));` 로 dark variant 정의.
- 색/반경 토큰은 :root 에 정의 → `@theme inline { --color-*: var(--*) }` 로 매핑해야
  Tailwind 유틸(bg-jp-bg, text-jp-fg, bg-primary ...)로 노출됨. @theme inline 안 거치면 유틸 생성 안 됨.
- JobPilot 팔레트 + shadcn semantic(--background/--primary/--border/--ring 등) 둘 다 매핑.
  radius 14px = --radius: 0.875rem.
- 다크가 기본: html className="dark" + body bg-jp-bg. .dark 블록도 동일 토큰으로 채워 shadcn 패리티.
