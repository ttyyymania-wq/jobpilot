# 자기소개서 — 김지원

## 1. 지원 동기
저는 "복잡한 데이터를 누구나 이해할 수 있는 화면으로 바꾸는 일"에 매력을 느껴 프론트엔드 개발자의 길을 걷고 있습니다. 현재 B2B SaaS 분석 대시보드를 만들며, 사용자가 수천 줄의 로그 대신 한 장의 차트로 의사결정하는 순간을 여러 번 목격했습니다. 귀사가 추구하는 "데이터 기반 제품 경험"이라는 방향이 제 지향과 정확히 맞닿아 있어 지원하게 되었습니다.

## 2. 성장 과정과 강점
주니어 시절 가장 크게 배운 것은 "측정하지 않으면 개선할 수 없다"는 것입니다. 첫 회사에서 막연히 "느린 것 같다"던 상품 페이지를 Lighthouse·Web Vitals로 수치화하니 LCP가 4초가 넘었고, 이미지 최적화와 코드 스플리팅으로 성능 점수를 68에서 92로 끌어올렸습니다. 이 경험 이후 모든 작업을 가설→측정→개선의 루프로 접근합니다.

현재 회사에서는 실시간 대시보드의 초기 렌더를 4.2초에서 1.1초로 단축했습니다. React Query로 서버 상태를 일원화하고, 무거운 차트를 가상화·지연 로딩하며, 불필요한 리렌더를 프로파일링으로 제거한 결과였습니다.

## 3. 협업과 팀 기여
혼자 빠르게 가기보다 팀이 함께 멀리 가는 것을 중요하게 생각합니다. 사내에 흩어져 있던 UI 패턴을 40여 종의 공통 컴포넌트로 정리하고 Storybook 문서를 붙여, 신규 입사자도 하루 만에 화면을 조립할 수 있게 만들었습니다. 그 결과 팀 전체 UI 개발 속도가 약 30% 빨라졌습니다.

## 4. 입사 후 포부
입사 후에는 (1) 단기적으로 제품의 핵심 화면 성능과 접근성을 끌어올리고, (2) 중기적으로 재사용 가능한 디자인 시스템을 정착시켜 팀의 개발 생산성을 높이며, (3) 장기적으로는 생성형 UI·AI 보조 도구처럼 사용자 경험을 한 단계 끌어올리는 새로운 인터페이스에 도전하고 싶습니다. 측정하고, 개선하고, 함께 성장하는 개발자가 되겠습니다.
